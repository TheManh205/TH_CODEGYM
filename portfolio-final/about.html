Về Tôi

Tôi là Lương Thế Mạnh, định hướng phát triển chuyên sâu về Lập trình Front-End. Tôi tập trung vào việc áp dụng các tiêu chuẩn web mới nhất bao gồm HTML5 Ngữ nghĩa, CSS Grid 2D, Flexbox và triết lý Mobile-First để xây dựng giao diện mượt mà trên mọi thiết bị.

Kỹ năng của tôi

  • Nền tảng Web: HTML5, CSS3, JavaScript (ES6+)
  • Bố cục & Styling: CSS Grid, Flexbox, Mobile-First Responsive Design, Art Direction
  • Công cụ & Quản lý mã nguồn: Git, GitHub (@TheManh205), VS Code, Netlify Drop
  • Tối ưu hóa: Web Performance Optimization, Accessibility (a11y), SEO cơ bản
